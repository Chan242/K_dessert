------------------------ 표 양식 1 ------------------------

텍스트 정렬 적당히 수정하며 사용하면 될듯합니다.


	table, tr, th, td {
		border-bottom: 1px solid #BEBEBE;
		border-collapse: collapse;
	}
	
	table {
		border-top: 2px solid black;
	}
	
	th {
		background-color: #F5F5F5;
		text-align: left;
	}

	th, td {
		padding: 15px;
	}

	.btn_style {
