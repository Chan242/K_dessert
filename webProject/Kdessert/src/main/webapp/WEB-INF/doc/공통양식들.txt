관리자 페이지 레이아웃 맞추기

0. 헤더와 사이드바를 인클루드한다

<jsp:include page="/page/admin/commPage/Adm_Header.jsp"/>
<jsp:include page="/page/admin/commPage/Category_Mgr.jsp"/>

1. 사이드바, 내용부분을 각각 div로 감싼 뒤, 두 div를 다시 div로 감싼다(wrap)

(예시)

	헤더
	<div>
		<div id="사이드바div">
			사이드바
		</div>
		<div id="내용div">
			내용
		</div>
	</div>

2. 사이드바div를 css에서 float: left;

3. 내용div를 css에서 width: 1300px; margin-left: 50px; float: right;

4. 내용div 내부 제일 위에 카테고리명 삽입: <h2 style="margin: 40px;">해당 카테고리 명</h2>

(예시)

	(생략)
	<div id="내용div">
		<h2 style="margin: 40px;">해당 카테고리 명</h2>
		내용
	</div>

5. 내용div 안에 있는 요소들의 width 조절해서 margin: auto; (혹은 임의로 조정)
	+추가의견: 메인 테이블은 width 1200px 정도가 적당한듯 합니다

	#container {

	}
	#div_category {
		float: left;
	}
	#div_content {

<div id="container">

	<div id="div_content">

	</div>
</div>

------------선택된 페이지에서의 메뉴 css 설정-------------------

카테고리 jsp의 <body>를 보면 a태그에 id가 설정되어 있습니다. → id="select_(카테고리)"
이 아이디를 참고하여 작업하시는 페이지(jsp)에서 CSS 설정을 해주시면 됩니다.

참고하는 카테고리jsp의 CSS 설정 중 a:hover 가

	.side_Menues a:hover {
		background-color: white;
		color: #64473E
	}

이렇게 설정되어있다면

작업 페이지에서 해당하는 id를 선택 후 위에 설정되어있는 내용을 그대로 적으시면 됩니다.

ex.

MemberListView.jsp

	#select_member {
		background-color: white;
		color: #64473E
	}
